Futsal Event Tracker
Use keyboard shortcuts to quickly select events and players. Press Enter to add an event without coordinates, or Backspace to remove the last event.

Help

Thanks for using this web app! Here's how to get started with collecting futsal event data:

Quickstart
  1. Select a pitch length and width using the dimension dropdowns.
  2. Select an event from the events menu via mouse or keyboard shortcuts in brackets.
  3. Select a player from the player menu via mouse or keyboard shortcuts.
  4. Click the area of the pitch where the action occurred.
  5. To record start and end points of an action, click and drag across the pitch.
  6. Press Enter to add an event without coordinates.
  7. Press Backspace to remove the last event.
Pitch Dimensions

Select the pitch length (38-42 m) and width (20-25 m) to match your venue. Coordinates are recorded in metres relative to the selected dimensions.

Customize Event and Player Details

Click Edit next to the Event, Home Player, or Away Player headings to customise labels. Jersey numbers and player names appear in exported CSV and PDF files.

Generate CSV and PDF Reports

Click Download CSV or Download Report to export data.
