Event tagging made simple and accessible.

Click on a sport to start tracking actions on the pitch or court, then export your data as CSV or generate a PDF report.

Quickstart
  1. Pick a sport (e.g., Football).
  2. Select player and action from the right-side controls.
  3. Click (or click-drag) on the court to record start/end coordinates.
  4. Use the table to review events; edit players via the “Edit” buttons.
  5. Export data via the Download CSV or Download Report buttons.

How to Use the App

Tagging Basics
  • Select a player (Home/Away) and an action type.
  • Click on the field to mark a point; click-drag to capture a start→end vector.
  • Events appear in the table; remove by clicking your UI’s delete/remove button.
  • Edit player labels (names, jersey numbers) to personalize the report.
Exports & Reports
  • CSV: All tagged rows with coordinates and metadata.
  • PDF: A per-player, per-action visualization (Matplotlib or mplsoccer).
  • Fonts: uses Vera.ttf if present; otherwise falls back to default.
  • Images are generated server-side with a non-interactive backend.
Keyboard Shortcuts (example)
  • G/H: Toggle Grip (Forehand/Backhand in Tennis).
  • 1–4: Select player buttons (A01/A02/B01/B02).
  • Z–.: Cycle shot types (as defined on the page).
  • W/U/F/R: Winner / Unforced / Forced / Rally.
  • Sports have different controls—open the page’s Help for specifics.
Data & Privacy
  • Default storage is in-memory per process (dev). Use a DB/Redis for multi-worker prod.
  • No personal data is required; player names are optional labels for reports.
  • CSV/PDF are generated on demand and downloaded to your device.

Help

Choose a sport to start tagging events on an interactive pitch or court.

Tips
  • Each sport page has its own controls and keyboard shortcuts.
  • Click once to mark a point; click-drag to mark start→end actions.
  • Use the “Edit” buttons to rename players/jerseys for clearer exports.
Troubleshooting
  • If PDF download fails, check server logs for font/image warnings.
  • If CSV columns look off, confirm your event schema on that sport page.
